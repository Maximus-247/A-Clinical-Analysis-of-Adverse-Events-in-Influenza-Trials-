# Adverse Events Analysis in Fluvir™ Clinical Trial
![image alt](https://github.com/Maximus-247/A-Clinical-Analysis-of-Adverse-Events-in-Influenza-Trials-/blob/c91c83f62b9a39c4b44330da756bfd8bc724b8a1/Screenshot%202025-04-30%20223146.png)

This project analyzes the occurrence of adverse events in a clinical trial comparing Fluvir™ to a placebo for treating influenza.


## Overview
The analysis includes contingency tables, chi-square tests, risk ratio and odds ratio calculations, and visualizations to assess treatment safety profiles.

## Methods
- Tabulation and percentage calculation of adverse events.
- Chi-square test for statistical significance.
- Risk ratio and odds ratio computation.
- Bar plots to visualize the absolute and relative frequencies of adverse events.

## Tools
- **R Programming Language**
- **tidyverse**, **scales**

## Key Findings
- Group 1 had a significantly higher rate of adverse events.
- The relative risk of adverse events was 18% higher in Group 1.
- Group 2 demonstrated a more favorable safety profile.
